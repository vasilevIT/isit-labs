# Результаты тестирования API

Запросы выполнены командой `curl` на локальном сервере (`php -S localhost:8000 -t public`) с исходными данными из `storage/`. Скриншоты — в папке `images/`.

## Задачи

| № | Запрос | Ожидаемый код | Получен код | Комментарий |
|---|--------|---------------|-------------|-------------|
| 1 | `GET /api/tasks` | 200 | 200 | массив из 7 задач |
| 2 | `GET /api/tasks?status=done` | 200 | 200 | 2 задачи (рис. 1) |
| 3 | `GET /api/tasks/3` | 200 | 200 | объект задачи |
| 4 | `POST /api/tasks` корректное тело | 201 | 201 | заголовок `Location: /api/tasks/8` (рис. 2) |
| 5 | `PATCH /api/tasks/8` `{"status":"done"}` | 200 | 200 | статус изменён, остальные поля прежние (рис. 3) |
| 6 | `PATCH /api/tasks/8` `{"status":"done","id":500}` | 200 | 200 | поле `id` не изменилось |
| 7 | `DELETE /api/tasks/8` | 204 | 204 | тела нет (рис. 4) |
| 8 | `DELETE /api/tasks/8` повторно | 404 | 404 | `{"error": "Задача не найдена"}` (рис. 4) |
| 9 | `GET /api/tasks/999` | 404 | 404 | (рис. 6) |
| 10 | `POST /api/tasks` `{"title":"Да","project_id":77,"status":"x"}` | 422 | 422 | три ошибки сразу (рис. 5) |
| 11 | `POST /api/tasks` тело `abc` | 400 | 400 | не JSON (рис. 5) |

## Общие

| № | Запрос | Ожидаемый код | Получен код | Комментарий |
|---|--------|---------------|-------------|-------------|
| 27 | `GET /api/nothing` | 404 | 404 | JSON-ответ, а не HTML-страница |
| 28 | `GET /tasks` | 200 | 200 | сайт из лабораторной работы №6 продолжает работать |

Примечание. Встроенный сервер PHP выводит в первой строке ответа для кода 422 слова «Unknown Status Code»: это особенность его таблицы названий кодов, сам код 422 и тело ответа верные.
