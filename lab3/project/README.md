# Структура программного проекта

Каталог `project/` — заготовка структуры будущего приложения (пустые каталоги с `.gitkeep`), подготовленная по итогам проектирования архитектуры. Наполнение кодом будет выполнено в последующих лабораторных работах.

```
project/
├── frontend/            # клиентская часть (SPA)
├── backend/
│   ├── controllers/     # обработка HTTP-запросов, валидация входных данных
│   ├── services/        # бизнес-логика приложения
│   ├── repositories/    # доступ к данным (работа с БД)
│   ├── models/          # модели данных (сущности)
│   └── routes/          # определение маршрутов API
├── database/            # миграции, схема базы данных
└── docs/                # техническая документация проекта
```
